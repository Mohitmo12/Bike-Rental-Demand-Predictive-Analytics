This project analyses 8,760 hourly records from Seoul’s bike-sharing system to understand what drives rental demand and how well it can be predicted. It covers data cleaning, feature engineering (cyclical encoding of hour, month and weekday), exploratory analysis, and a chronological train/test split to avoid data leakage. Regression models predict the exact number of rentals, classifiers label each hour as Low, Medium or High demand, K-Means and hierarchical clustering group similar hours, and Apriori finds “if-then” rules linking time, weather and demand. Multiple Linear Regression was the best regression model (R² = 0.463), and SVM was the best classifier (71% accuracy, ROC AUC 0.876). Demand peaks at 8 AM and 6 PM, and summer demand is over four times winter demand.
